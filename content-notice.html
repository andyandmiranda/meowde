학습 콘텐츠 안내

Meowde의 Linux 학습은 특정 교육기관의 공식 강의·인증 과정이 아닌 독립적인 학습 경험입니다.

이 레슨의 설명과 연습 시나리오는 일반적인 Linux 개념을 학습하도록 구성했습니다. 외부 교육 과정과의 공식 제휴·인증을 의미하지 않습니다. 공개 문제의 독창성과 외부 자산 사용 조건은 별도로 점검하고 있습니다.

명령어 입력은 제한된 브라우저 시뮬레이션입니다. 실제 운영체제의 모든 동작을 재현하지 않습니다. 첫 폴더 레슨은 제출마다 새 연습 공간에서 결과를 확인합니다. 연습용 파일은 기기의 파일이 아닙니다.

첫 폴더 레슨의 단계·입력·통과 답안·힌트 사용과 완료 기록은 이 브라우저에만 저장됩니다. 계정 동기화나 서버 전송은 하지 않습니다. 기기·브라우저를 바꾸면 이어지지 않고, 브라우저 데이터를 삭제하면 복구할 수 없습니다. 이전 버전 학습 기록은 기존 저장 공간에 보존됩니다. 외부 자료의 이용 권한이 확인되지 않은 과제와 원문 요약은 현재 학습에서 제외했습니다.
