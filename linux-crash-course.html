Linux 하루 완주

Ubuntu 설치 없이 개념과 명령어를 연습해요. 이 화면의 터미널은 실제 시스템 명령을 실행하지 않는 안전한 학습 예시입니다.

단원 선택 · E1~E9

모바일 가상 터미널

실제 Ubuntu가 아닌 브라우저 안의 임시 파일 시스템이야. pwd, ls, cd, mkdir, touch, cat, cp, mv, head -n, tail -n, grep, find -name을 연습할 수 있어. app.log에는 연습용 로그가 들어 있어. 다른 파일이나 서버에는 접근하지 않아.

상태 기반 실습 미션 · 개념 → 실습 → 힌트 → 채점 → 재도전

student@meowde:/home/student$

이 페이지의 진도는 별도 브라우저 저장 공간에 보관돼요. 기존 MEOWDE Linux 학습 기록을 삭제하거나 변경하지 않습니다. 문제와 예시는 독창적으로 작성한 교육용 연습이며 실제 Ubuntu 명령 실행 결과와는 차이가 있을 수 있습니다.
