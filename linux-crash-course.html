모바일 가상 터미널

실제 Ubuntu가 아닌 브라우저 안의 임시 파일 시스템이야. pwd, ls, cd, mkdir, touch, cat, cp, mv, head -n, tail -n, grep, find -name을 연습할 수 있어. app.log에는 연습용 로그가 들어 있어. 다른 파일이나 서버에는 접근하지 않아.

상태 기반 실습 미션 · 개념 → 실습 → 힌트 → 채점 → 재도전

미션을 바꾸면 임시 파일과 폴더가 초기화돼요. 완료한 개념 퀴즈 기록에는 영향을 주지 않아요.

student@meowde:/home/student$

E8·E9 변수와 조건문

Bash 조건식의 실행 흐름을 숫자를 바꿔 가며 확인해 봐. 학습용 조건 평가이며 입력한 셸 스크립트를 실제 실행하지 않아.

숫자를 입력하고 확인해 봐.

연산자 -lt는 작다, -ge는 크거나 같다는 뜻이야. then과 else 중 실행할 분기를 비교해 봐.

E9 · 직접 조건문 작성

제한된 Bash if 문법을 작성하고 여러 입력값으로 결과를 검증해 봐. 실제 셸 코드는 실행되지 않아.

직접 코드를 작성하고 채점해 보세요. 초기 코드는 제공하지 않으며 정답은 여러 입력값으로 검사해요.
