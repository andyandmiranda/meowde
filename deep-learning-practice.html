가중치를 한 번 직접 바꿔봐요

개념 → 예시 → 직접 조작 → 적용 → 회상. 이 실습은 브라우저에서 숫자를 계산하며, PyTorch를 실행하지 않아요. 기록을 저장하거나 변경하지 않습니다.

① 개념

모델이 예측한 숫자와 정답의 차이를 손실로 나타내요. 손실의 기울기를 이용하면 가중치를 수정할 수 있어요.

식: 예측 = w × x, 손실 = (예측 − 정답)², 기울기 = 2 × (예측 − 정답) × x

② 따라 보기

입력 x=2, 정답 y=6, 시작 가중치 w=1.

예측2.00
손실16.00
기울기−16.00
가중치 w1.00

w=1이면 예측은 2예요. 정답 6과 차이가 4이므로 손실은 16이에요.

③ 직접 조작

w를 바꾸면 예측과 손실도 바뀌어요.

④ 새로운 문제

현재 w=1, x=2, y=6일 때 학습률 0.1로 한 번 업데이트하면 가중치가 얼마일까요?

⑤ 회상

정답보다 예측이 작고, x가 양수라면 이 예제에서 가중치는 어느 방향으로 바뀌어야 할까요?

다음 단계: PyTorch 구현

아래 코드는 학습할 코드 예시예요. 이 페이지에서는 실행되지 않으며, 실제 PyTorch 환경과 모델 학습·검증 기능은 아직 개발 대상이에요.

import torch
w = torch.tensor(1.0, requires_grad=True)
x = torch.tensor(2.0)
y = torch.tensor(6.0)
loss = (w * x - y).square()
loss.backward()
with torch.no_grad():
    w -= 0.1 * w.grad
print(round(w.item(), 1))  # 2.6

이 화면은 기존 17단원·51문항 및 모든 기존 저장키에 영향을 주지 않아요.
