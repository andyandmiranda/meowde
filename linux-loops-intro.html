반복문: 같은 일을 여러 번

이 단원은 기존 E1~E9의 완료·점수·진도 기록을 바꾸지 않는 독립 보충 학습입니다. 실제 Bash 실행이나 강의 원문 실습을 대체하지 않습니다.

1. 왜 반복할까요?

같은 명령을 세 번 적지 않고, 값이 달라질 때마다 한 번씩 실행할 수 있어요. for는 목록에서 값을 하나씩 꺼내는 반복문입니다.

for name in cat dog; do
  echo "$name"
done

첫 번째에는 name=cat이므로 cat을 출력합니다. 두 번째에는 name=dog이므로 dog를 출력합니다. done에서 반복문이 끝나요.

주의: do와 done은 Bash 문법이며, 변수를 읽을 때는 $name처럼 $를 붙여요.

2. 함께 풀기

다음 코드는 몇 줄을 출력할까요?

for x in one two three; do
  echo "$x"
done

3. 혼자 적용하기

다음 코드의 실제 출력은 무엇일까요?

for n in 2 4; do
  echo "$n"
done

개념·예제 다시 보기

for 변수 in 값1 값2; do 다음의 명령이 각 값마다 실행되고, done에서 끝납니다.

4. 자주 하는 실수

echo "n"은 n이라는 글자를 출력해요. echo "$n"만 변수 값을 출력합니다. 또한 목록의 항목 수가 반복 횟수를 결정합니다.

정답을 틀려도 선택한 답과 올바른 답·원인을 알려줍니다. 답안은 브라우저에 저장하지 않으며 XP·츄르도 지급하지 않습니다.
