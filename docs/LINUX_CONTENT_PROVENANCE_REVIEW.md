# Linux 공개 콘텐츠 권리·출처 점검 (2026-10-15)

상태: **부분 확인 / 공개 승인 아님**. 검토자: MEOWDE Product & Engineering Lead (자동 코드 감사). 법률 전문가의 독립적인 검토는 이루어지지 않음.

## 현재 관찰

- Production `main/robotics.html`에는 외부 교육 과정 이름 `NVIDIA AI Campus · STEP 1`과 관련된 과제·강의 맥락이 남아 있음. 권리 및 공식 관계 여부 **미확인**.
- Draft PR #83의 `robotics.html`은 기존 저장 기록만 읽는 화면이고, 신규 `linux-home.html` / `linux-start.html`의 메인 흐름은 자체 작성한 `mkdir` 개념, `training` 및 `travel` 폴더 생성 연습을 사용함.
- `linux-crash-course.html`은 E1~E9의 명령어 설명과 브라우저용 자체 예제·미션을 포함함. 원문의 문항과 체계적으로 대조 검수하지 않았으므로 **독립성 최종 검증 미완료**.
- `assets/meowde-approved-headphones.svg`의 사용 승인은 제품 내부 명칭/기존 승인으로 표현되어 있으나, 원본 제작 경위 및 배포권 증빙은 이번 감사에서 검증하지 못함.
- Pretendard 외부 폰트 CDN, 라이브러리/이미지 등 제3자 자산의 라이선스 및 고지 의무는 별도의 배포 전 점검이 필요함.

## 공개 전 차단 항목

1. 과거 강의 내용·문항과 공개 파일의 문구 및 문제 구성 직접 대조. 동일·실질 유사 문항은 독창적인 시나리오와 정답·해설로 교체.
2. 외부 기관 이름이나 로고가 공식 후원·제휴·인증으로 보일 수 있는 표현을 공개 화면과 메타데이터에서 제거하거나 정당한 이용 근거 기록.
3. 각 파일/이미지/폰트/코드의 출처, 저작자, 라이선스 URL, 사용 조건과 고지 의무를 검증한 뒤 기록.
4. 학습 문제의 정확성, 정당한 명령어 대안, 브라우저 가상환경 제한과 모바일 접근성 검증.
5. 저장 기록 키 `meowde-linux-robotics-v1` 보존 및 URL 호환성 확인. 기존 Production 페이지를 단순 삭제하지 않음.

## 적용 경계

이 기록은 외부 교재의 저작권 침해를 확정하는 법률 판단이 아님. **출처 표기만으로 복제 허가가 생기지는 않음**. 불확실한 소재는 공개 전 보류한다.

승인권자: PO. 현재 PR #83은 Draft, Production 미반영. 검증 가능한 라이선스 근거와 콘텐츠 QA가 확보될 때까지 출시 승인 보류.

| 단원 | 공개된 주요 내용 | 출처·위험 검토 상태 |
|---|---|---|
| E1 | pwd, ls, 파일·디렉터리 생성 | 표준 명령어 설명; 외부 자료 대조 미실행 |

| E4 | 파이프, 리다이렉션, sort, wc | 일반 명령 원리; 외부 자료 대조 미실행 |

**이번 변경:** `linux-crash-course.html`의 E9 설명 예제와 퀴즈를 `battery=25`에서 충전 필요 여부를 판별하는 상황으로 교체. E2·E3 출력과 파일명을 실제 가상 파일 시스템에 맞춤. 이 변경은 저작권 침해 여부의 확정 판정이나 전체 E1~E9 검토 완료를 의미하지 않음.
