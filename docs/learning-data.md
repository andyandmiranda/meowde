## 새 기록의 의미

- `version:1`, `step:0..4`, 최대 180자 `input`, `solutions.training/travel`, 단계별 `hints`(0..2).
- 완료는 training·travel 폴더 생성 결과가 각각 별도 초기 시뮬레이터에서 재검증되고 마지막 단계에 도달한 경우다. 임의의 `completed:true`는 신뢰하지 않는다.
- 답안 수정은 해당 단계의 통과 판정을 취소한다. 매 제출을 새 가상 파일 상태에서 평가하여 이전 실행 결과로 오답이 통과하지 않게 한다.
- 새로고침 시 통과 답안을 재평가한다. 단계 숫자만 높고 증거가 없으면 필요한 실습 단계로 돌아간다.
- 힌트 사용은 그 단계에서 도움 버튼을 눌렀다는 기록이다. 버튼을 누르지 않았다고 외부 도움 없이 숙달했다고 단정하지 않는다.
- 입력은 이 브라우저의 localStorage에만 보관한다. 서버로 전송하지 않는다. 개인·비밀 정보를 입력할 필요가 없는 일반 폴더 이름 과제다.

## 실패·복구·롤백

- 새 키의 JSON/버전이 읽히지 않으면 원본을 덮어쓰거나 지우지 않는다. 이번 연습은 메모리에서 진행하고 저장 불가를 표시한다. 원본 내보내기·복구 UI는 현재 제공하지 않는다.
- 브라우저 저장 제한·용량 부족이면 학습을 계속할 수 있지만 저장 실패를 표시한다. 저장에 성공했다고 표시하지 않는다.
- 다른 기기·브라우저·도메인은 저장 공간이 다르다. Preview와 Production 사이에도 자동으로 옮겨지지 않는다. 브라우저 데이터 삭제 후 서버 복구는 불가능하다.
- 여러 탭에서 동시에 같은 레슨을 수정하면 마지막 저장이 우선한다. 다중 기기 동기화·동시 편집 충돌 해결은 미구현이다.
- 코드 롤백은 이전 배포로 되돌린다. 새 키는 삭제하지 않고 남겨 둬 재배포 시 다시 사용할 수 있게 한다. 기존 키의 역마이그레이션은 필요 없다.
- 서비스 워커 캐시 세대는 `meowde-v463-learning-resume`. 캐시 교체는 학습 localStorage 삭제와 분리된다. 이전 버전에서의 캐시 갱신과 실제 모바일 설치 앱은 별도 출시 점검 대상이다.
