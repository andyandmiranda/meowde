## 승인 경계

- 이 기록은 작업 승인 증거를 요약한다. 존재하지 않는 PR 댓글·서면 승인 링크를 만들지 않는다. 이 대화의 사용자 승인을 근거로 하며, PR 본문에도 범위를 기록한다.
- Production 승인은 최종 커밋·검증 환경·남은 위험·롤백 계획에 연결하여 별도로 받는다. 침묵·CI 성공·Preview READY는 승인이 아니다.
- 자동화 생성이나 다른 대화에 대한 메시지 전송은 이번 작업에 포함하지 않는다.
