상태: **부분 완료 / PR #85 검토 대상**. main 병합과 Production 배포 승인이 아니다. 구현·검토·검증은 같은 Codex AI이며 독립 검토는 아니다.

## 이번 변경

- 기존 #86의 최초 정답률 수정을 재검증하고 KO/EN 표시를 명확히 했다. 실제 첫 레슨에서 4/5 후 재시도 성공은 80%이며, 최초 오답은 유지된다.
- 실행 중/이미 채점한 답안의 중복 제출을 막아 중복 실행·정답 수·보상을 방지했다.
- Python 파일 줄 세기 디버깅 문항의 잘못된 수정 예시를 KO/EN에서 바로잡았다. OOP 예제·출력 예측 10곳에 빠진 클래스/변수 정의를 명시했다.
- 손상된 Python 기록 자동 삭제와 Linux 퀴즈 기록 덮어쓰기를 막았다. 복구가 필요한 원본은 유지하고 저장 제한을 알린다.
- Linux E2의 파일 읽기 실습과 E8/E9 연결을 바로잡고 tail 미션을 추가했다. 실행 실습이 없는 단원은 개념 퀴즈만 제공한다고 표시한다.
- `/learning-path.html`에서 실제 Python 60레슨·Linux 10학습 단위와 미완료 범위를 확인한다.
- `?tester=1`일 때 Python 문제, Linux 첫 안내 레슨과 개념 퀴즈에서 신고 초안·미리보기·복사를 제공한다. 서버 접수·네트워크 전송·답안/출력 자동 첨부는 없다. 초안은 대화상자 메모리에만 존재한다.
- 집중 복습은 **Python 첫 레슨의 출력 / Linux 첫 폴더 만들기 개념만 파일럿**이다. 틀린 문제 → 개념 → 검증된 유사 문제 → 응용 → 이해도 확인. 다른 단원의 전체 집중 복습으로 표시하지 않는다.

## 기록 호환성

기존 진도 키·레슨 ID·기존 완료 기록을 삭제하거나 마이그레이션하지 않는다. 기존 Python 재시도·완료 보상은 유지한다. 집중 복습은 기존 진도와 XP를 늘리지 않는다.

추가 키:

- `meowde-python-focused-review-v1`
- `meowde-linux-focused-review-v1`

새 기록은 앞으로 관찰한 오답만 보관한다. 기존 총점에서 과거 오답을 추정하지 않는다. 최초 오답 일시와 재시도 성공, 단계별 최초 정오답·성공·도움 이력을 구분한다. 원시 코드·명령어·실행 출력은 이 기록에 저장하지 않는다. 알 수 없거나 손상된 새 기록은 덮어쓰지 않고 기존 학습은 계속 사용할 수 있다.

Python 진행 중 복습은 기존 시작 보호 화면을 사용한다. 현재 학습을 유지하려면 ‘현재 학습 이어하기’를 선택하거나 레슨 완료 뒤 복습한다. Linux 복습은 기존 안내 레슨/퀴즈 기록을 쓰지 않는다. Linux 복습의 단계·결과는 복구하지만 입력 문자열은 저장하지 않는다고 화면에 알린다.

## 구현과 검증을 구분한 학습 범위

| 과목 | 구현된 단위 | 자동 확인 | 아직 완료로 볼 수 없는 범위 |
|---|---:|---|---|
| Python | KO/EN 각 60레슨, 각 320문항 | 실제 Pyodide 작성 모델 120개, 오답 120개, 추가 테스트 대상 고정 출력 거부 68개, 출력 예측 160개; 60레슨씩 화면 진행 | 전체 문항 해설의 교육적 타당성·초보자 이해도·낯선 문제 독립 해결 능력 |
| Linux | 첫 안내 레슨 + E1~E9 = 10학습 단위 | 첫 안내 흐름·기록 보존, 개념 퀴즈, 제한된 파일/검색·Bash 조건 평가 | 편집기·소유권·프로세스·파이프·리다이렉션·셸 반복·종합/방탈출 실습 |

Python 빈칸/디버깅 조각의 컴파일 검사는 전체 의미 검증이 아니다. 일부 조각은 앞서 제시한 문맥을 요구한다. 출력 예측의 ‘오류 발생’, ‘출력 없음’, ‘첫 줄’ 같은 질문 범위를 실행 결과와 구분해 검사한다.

Python 예상 학습 시간 5~15시간, 현재 Linux 범위 1~2시간은 계획용 추정이며 관찰한 학습 완료 시간이 아니다. Linux 전체 과정 완성은 **아니다**.

## 검증 방법과 접근 한계

자동 검사는 실제 로컬 Chrome/Pyodide와 독립 합성 학습자를 사용했다. 전체 과정 진행은 정답 모델을 사용하는 자동 화면 검사이며 사람의 학습 성취 평가가 아니다. 모바일 320/375/390/768px, 키보드, 새로고침·과목 왕복·손상 기록·저장 실패·오프라인 복구를 별도로 검사한다.

고정 Hosted Preview는 새 Chrome 세션에서 Vercel 로그인으로 이동했다. Hosted 학습 E2E는 **NOT RUN**이며, 보호 우회·공유 토큰·인증 설정 변경을 하지 않았다. Production 동작 검사는 **NOT RUN**이다. 배포 메타데이터의 Production SHA와 이번 작업의 main/Production 미변경 여부는 별도로 대조한다.

최종 커밋별 결과·CI·고정 Preview 주소는 PR #85 및 Issue #78의 최종 인계 댓글을 따른다. 직전 커밋의 CI 성공을 후속 커밋 성공으로 취급하지 않는다.

## 롤백과 통합

이번 변경 커밋만 되돌리고 신규·기존 localStorage 키는 삭제하지 않는다. 새 집중 복습의 활성 큐는 기존 문제 유형으로 구성되어 있으며 기록 복구를 위해 데이터는 보존한다. 다른 Python 심화 작업의 `feature/python-learning-depth`는 이 작업에서 수정·통합하지 않았다. 공통 `package.json`, `sw.js`, `v434-release.js`는 병합 전에 명시적으로 조정하고 전체 회귀를 다시 실행해야 한다.
